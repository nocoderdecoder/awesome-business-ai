# Plain-English AI glossary

You can use this directory without memorizing technical vocabulary. Here are a few terms you'll see on product websites.

| Term | What it means in everyday language |
| --- | --- |
| Artificial intelligence (AI) | Software that can do tasks such as creating content, recognizing patterns or organizing information. |
| Generative AI | AI that creates text, images, audio or other content from a request. |
| AI assistant | A tool you can ask questions or give tasks to in ordinary language. |
| Prompt | The question or instruction you enter into an AI tool. |
| Model | The system a tool uses to generate an answer or output. |
| Hallucination | When a system produces incorrect or invented information that may sound convincing. |
| Automation | Steps that happen with less manual work. The process still needs appropriate controls. |
| AI agent | A system that may take multiple steps or use tools to complete a task. |
| Integration | A connection between products, such as a meeting app and a task tracker. |
| Human review | A person checks and approves important work before it is used. |
| Data privacy | Rules for how information is collected, shared, accessed and retained. |
| Pilot | A small trial used to learn whether a tool actually helps before wider use. |
